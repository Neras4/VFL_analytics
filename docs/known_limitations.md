# Известные ограничения

v0.2.1 проверяет опубликованные математические компоненты и интерфейсы.
Сила состава — частичная модель; порядок сочетания всех механик не доказан.
Интервалы — консервативные множества возможностей, не доверительные интервалы.
Эвристическое ранжирование использует явно названный subtotal известных
компонентов и не гарантирует глобальный оптимум с нелинейными эффектами.

Нет OBSERVED-проверок на реальных игровых данных или replay генератора.
15 выбранных векторов исследования имеют исходную классификацию SYNTHETIC.
RULE_REFERENCE отдельно применяется к опубликованным числовым примерам и
табличным значениям. Зелёные тесты не доказывают совпадение с генератором.

Названия стилей из Assistant не доказывают идентичность реального стиля
при неполной изученности. Кандидатные множества экспортера не нормализованы;
применяются общие границы. Нет end-to-end подтверждения на реальном экспорте.
Минуты должны быть заранее собраны с правильной семантикой; передачи между
клубами могут менять знаменатель. План доступности и календарь не загружаются.

Возрастная капитанская таблица точна в допустимом домене; оптимизатор применяет
её к частичной силе, которая не равна опубликованной реальной позиционной
силе. Ка не реализована; капитан с ней пропускается с предупреждением.
Без геометрии взаимопонимание явно исключено из subtotal.

Не реализованы полный набор спецвозможностей, погодная таблица, новые
позиционные преобразования, CP-SAT, обученная вероятность победы, симулятор,
MCP/VPS, авторизация, новые парсеры и изменения расширения. Нет финансового
ROI, налога, комиссий, резерва и зарплатной модели. Вероятности противника
и Monte Carlo решения остаются прежними непроверенными модельными сценариями.
