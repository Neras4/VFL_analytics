Исходные 12 тестов сохранены. Обоснованно обновлены ожидания трёх функций:
`test_growth_and_defense` (19.9% → 20%, +10),
`test_usefulness_projection_denominator_increases` (251/931 вместо 260/940
и неизвестная достижимость), `test_chemistry_directed_and_same_nation_floor`
(типизированные результаты; неполная изученность не подтверждает actual style).

В fixtures включены **15** выбранных векторов из research `test_vectors.json`:
четыре DEV.USEFULNESS, один DEV.YOUTH.MINUTES, пять CHEMISTRY_LINE,
один CHEMISTRY_PLAYER, четыре CAPTAIN_AGE. Исходные id и classification

это из 20% изученности. Для обычного экспортированного названия такой вывод
запрещён. RULE_REFERENCE-тесты отдельно используют опубликованные примеры
округления, возрастные коэффициенты, молодёжную таблицу и нулевые концы.
OBSERVED-проверок нет. Синтетические данные не доказывают совпадение с генератором.

## Сверка правил и неоднозначности

Проверены официальный page=40 v19.2 (капитан §2.8, стиль §2.10,
взаимопонимание §2.12) и page=70 v14.0 (§2–3, домен возраста).
Числа и смысл шести исправлений согласуются с аудитом. Прямых численных
противоречий в этих компонентах не найдено.

Есть смысловые ограничения: §2 page=70 задаёт любые клубы/сборные и владельца
на конец сезона, тогда как описание текущей ветеранской «ромашки» в §6 говорит
об играх за свою команду. Поэтому API моделирует сезонную полезность §2,
а не утверждает совпадение с текущим UI-индикатором. Неполное знание actual
style и процент изученности — различные входы; исследовательский same_style
не должен автоматически возникать из текстового экспорта. Порядок полной силы
и точные численные position/style-бонусы не установлены и остаются backlog.
Page=70 получена через www-зеркало; свежесть live-версии через веб-инструмент
не гарантируется. HTML-снимки не включены, версии и контрольные суммы сохранены.
