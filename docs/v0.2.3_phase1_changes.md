## Changes

- New snapshots boundary: timestamp ordering, matching team/kind, latest roster
  membership/state including null, stable-ID profile joins, section provenance,
  equal-time conflicts rejected. Statistical scopes are whole observations.
- Adapter recognizes unknown style text, preserves salary fallback from info,
  diagnoses conflicting contract salaries, distinguishes null specials from a
  known empty list, and isolates malformed optional records. Source evidence is
  private when input is private; no game login or action is performed.
- Separate market adapter: 0/50/38 rows accepted, 0 rejected. 50 of 63 marked
  incomplete; requested/applied sort separate, multistyle sets retained, no roster
  contamination or transfer utility model. Two bid states stay independent: 0 then
  1 active bid, with purchase limits/price/status/competing count/time preserved.
- Reproducible local_validation runner produces private inventory, ID joins,
  component reports and lineup candidates. Public fixtures are minimized
  anonymized structural examples with replacement financial values.
- Chemistry links now reject malformed endpoint types, self-links, absent slots
  and reverse duplicates using ValueError. Links are undirected.
- External numerical style-position coefficients support source/rule version/
  verification status/units. They remain ESTIMATED research scenarios. Legacy
  inputs keep support with explicit unverified provenance.
